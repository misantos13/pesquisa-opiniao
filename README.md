Projeto desenvolvido para atividade de **Desenvolvimento de Sistemas I - Agenda 08**. Tendo a proposta de fazer uma **Pesquisa de Opinião**  recolhendo informações como **Nome**, **Idade** e **Satisfação** do usuário.

---

# Objetivo do Programa 📝

Esse projeto tem como objetivo recolher informações sobre a satisfação dos clientes com o atendimento da empresa, coletando o **nome**, a **idade** e **grau de satisfação** fornecidos por clientes e apresentando a quantidade votos de pessoas por grau de satisfação em categorias solicitadas.

**Condições:**

* Pesquisa deve ser feita com 50 clientes
* Coletar **Nome, Idade** e **Grau de Satisfação (Excelente, Bom e Ruim)**.
* Apresentar a quantidade de cliente que opinaram com grau de satisfação **"Excelente"** e **"Ruim"**.

---

**Objetivo da atividade:**
* Publicação do código-fonte através do Git e GitHub
* Prática da Lógica de Programação
* Desenvolver raciocínio lógico utilizando estrutura de repetição **"For"** e estrutura de decisão **"If / Elif"**.

# Como Utilizar? 👨‍💻

**Pré-requisitos**

→ Ter o Python 3 instalado no computador.

Para verificar se o Python está instalado, execute no terminal:

```bash
python --version
```
---

**Executando o projeto**

→ Clone este repositório:

```bash
git clone https://github.com/misantos13/pesquisa-opiniao.git
```

→ Entre na pasta do projeto

→ Execute o programa `app.py`

---
# O que fazer no Programa 🤷‍♂️

→ Inicie o programa.

→ Informe o **nome**, **idade** e **grau de satisfação**. 

→ Ao final da coleta de dados, o programa irá informar a quantidade de notas **"Excelentes"** e **"Ruins"**

>**Atenção!**
>
>A coleta de dados será feita 50 vezes antes de apresentar a quantidade de notas "Excelentes" e "Ruins"
>
>Exemplo de como fica a execução do programa com **10 clientes** pode ser encontrado em **"Prints"**
